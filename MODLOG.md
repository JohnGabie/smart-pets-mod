  Result: 6513 classes in 537 packages indexed, 402673 call references; init also clones java-callgraph2 from GitHub and builds it with Gradle 9.3 (network + build at init time). Cache `~/.cache/mcdev-mcp` is about 1.0 GB (outside the repo). Disk free afterwards is fine (82 GB before).

## 2026-10-18 - S11 time source adapter (Task 2)
- API names from the plan verified against decompiled 26.2 sources (mcdev static tools) and then by compiling: `MinecraftServer#clockManager() : ServerClockManager`, `ServerClockManager#getTotalTicks(Holder<WorldClock>)`, `#moveToTimeMarker(Holder<WorldClock>, ResourceKey<ClockTimeMarker>) : boolean`, `Timeline#getPeriodCount(ClockManager) : int`, `Timelines.OVERWORLD_DAY` (= minecraft:day, period 24000), `WorldClocks.OVERWORLD`, `ClockTimeMarkers.{DAY,NOON,WAKE_UP_FROM_SLEEP}`. All compiled unchanged; no deviation.
- Day = `Timelines.OVERWORLD_DAY` period count over the overworld clock; fallback `floorDiv(clock, 24000)` if a datapack removes the timeline (reported as `fallback=true`).
- Observed in `bash scripts/qa/run-client-gametest.sh` (exit 0, `OK range=16..235`, `SMARTPETS_S11_OK`): `time set 10d` -> day=10 clock=240000; `time add 1d` -> day=11; `moveToTimeMarker(WAKE_UP_FROM_SLEEP)` -> day=12 (jumps to next day start); `advance_time false` freezes clock while gameTime advances; `advance_time true` runs it again; `time set 1000` after day 12 -> day=0 clock=1000 (backwards, so ages must be monotonic); `time set noon` stays day 0 (clock 6000); `time set day` at clock 6000 -> clock 25000 day 1 (marker moves forward); command in the nether reports the same overworld day.
- Real bed sleep is NOT exercised: simulated by the call vanilla makes on wake-up; real sleep needs a human playtest.
- `SMARTPETS_TIME` appears twice in the log per invocation (mod logger + vanilla echo of the log line via command feedback), not once as the plan expected.
- Gotcha: the plan's python-free edit of the gametest by string replace silently missed because of tab depth; check diffs after scripted edits.
- S11 review fixes: the brief's `grep -c SMARTPETS_TIME == 1` check was replaced. The vanilla command feedback echoes each line, so the count is 2 per invocation, and one count cannot tell a plain call from a nether or anomaly call. The runner now greps exact lines tagged `(smartpets)` (3 invocations; 2 plain `day=1 clock=25000`; 1 `day=0 clock=1000 ... anomaly=CLOCK_BACKWARDS`), and the GameTest asserts the journal holds CLOCK_BACKWARDS and 3 TIME_SAMPLE entries. Proof: with the command literal renamed (`timex`), the run fails (`S11 failed: 9 journal has CLOCK_BACKWARDS`, runner exit 1); reverted.
